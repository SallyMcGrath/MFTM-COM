# Music for the Many — temporary page

Placeholder site for [Music for the Many](https://music4themany.com/) while the main site is down.

Registered Charity no. 1185526.

## Serve locally

```bash
npx --yes serve .
```

Or open `index.html` directly in a browser.

## Deploy / route

Point your host or DNS at this folder’s static files (`index.html` at the root). Works with Netlify, Cloudflare Pages, nginx, S3, GitHub Pages, etc. No build step.
